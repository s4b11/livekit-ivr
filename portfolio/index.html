03 — About

Curious by nature. An engineer by practice.

Most of my work is conversational voice AI: making an agent take turns naturally, hear domain terms correctly, and answer without long silences — then measuring it, so problems show up in data instead of in a live conversation.

Outside work I build small, readable open-source tools that test one idea end to end, like how the structure of knowledge changes an LLM’s answer. I like useful questions, tidy systems, and understanding why something works.
